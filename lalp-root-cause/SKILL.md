# Principle: Root cause

- A symptom gets reproduced; a cause gets proven.
- Reproduce → locate the mechanism → fix the mechanism.
- Adding a guard that papers over the symptom without touching the mechanism is debt that will come back.
- If you can't explain why the fix works, you don't yet know the cause.
