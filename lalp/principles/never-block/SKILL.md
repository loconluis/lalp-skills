# never-block

Every "should I continue?" costs a round-trip; for unattended runs it costs the night. Default to acting, then reporting what was done and what would have been asked.

Rules:

- Reversible → do it, log it.
- Irreversible (deletes, publishes, spends) → confirm — or skip-and-queue when unattended.
- Ambiguity → conservative reading, named in the log, proceed.
- The exception list stays short on purpose. If everything needs approval, nothing moves.
